# grant-discovery-platform
App to provide information about grants available to small businesses. In addition to assisting them through the process with templates and process tracking. 
# Grant Discovery Platform

AI-powered grant discovery platform for small businesses.

## Features
- AI-powered grant matching
- User dashboard and tracking
- Payment processing
- Mobile responsive design

## Quick Start
1. Clone this repository
2. Open `frontend/index.html` in your browser
3. For full functionality, run the backend server

## Deployment
- Deploy to Vercel, Netlify, or Heroku
- See docs/DEPLOYMENT_GUIDE.md for instructions
